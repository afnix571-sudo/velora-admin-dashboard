
# VELORA Admin Dashboard

A modern admin dashboard interface designed for managing the VELORA luxury fashion e-commerce store.

## Features
- Admin dashboard overview
- Product management interface
- Sales and analytics visualization
- Order management interface
- Modern and responsive UI
- Dashboard navigation

## Technologies
- HTML
- CSS
- JavaScript
- Tailwind CSS
- Chart.js

## Project Type
Portfolio Project / Demo

## Live Demo
https://velora-admin-dash.netlify.app

## Note
This is a demonstration project created for portfolio purposes. It does not include a production-ready secure backend or real payment processing system.
